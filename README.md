### Instalación

#### 1. Clona el repositorio
```sh
git clone ${repo url}
```
#### 2. Instala las dependencias
```sh
pnpm install
```

#### 3. Crea un archivo `.env` en la raíz del proyecto
```env
TOKEN=your_token
```

Con eso ya deberías tener el bot funcionando, ahora puedes probarlo con el siguiente comando:
```sh
pnpm dev
```

### Documentación
Por ahora no hay documentación, pero puedes ver los comandos disponibles con `!help`.

### Contribuir
Si eres desarrollador y tienes que aportar algo al bot, puedes hacer un fork o un clone del repositorio y luego hacer pull request.

> [!CAUTION]
